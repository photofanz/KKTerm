# Vietnamese localization audit — issue #804

Audited main `dba6eb31a0961d3714a970c44183d478512d11f2` on 2026-10-22.
No StringLane or other third-party installer was used. Comparison uses the
repository JSON, Python/Node standard libraries and the existing i18next runtime.

## Findings and scope

- 5,323 leaf keys, counting arrays as one leaf, unchanged in all 14 locales.
- Before: 805 identical scalar strings, including 384 multi-word values
  (multi-word means Python `len(value.split()) > 1`, including templates).
  This is a fresh audit, not a reproduction of the reporter's older 167 count.
- Translated 500 identical scalar strings: 304 multi-word and 196 single-word.
- Corrected 8 additional stale-English scalar strings against current `en.json`.
- Translated all 200 entries of `ai.waitingPhrases`, preserving length/order.
- Total: **708 string values across 509 leaf keys** (508 scalar keys + 1 array).
- After: 305 identical scalar values, 80 of them multi-word, retained after review.
  The shared 100-name `ai.tmuxSessionLabels` array and five proper game titles
  inside `ai.createWidgetExamples` also remain unchanged.

## Review decisions

Keep literal commands, JSON/header examples, paths, URLs, shortcuts, brand and
product names, language autonyms, units, protocol/format identifiers and established
technical terms. A sentence containing SSH, URL, AI or a command is still prose
and must be translated. Single-word actions such as Save, Cancel and Delete are
translated too. No shared-English percentage or blanket regex exemption is used.
The exact retained values and contextual reasons are recorded in
[`../../scripts/locale-quality-exceptions.json`](../../scripts/locale-quality-exceptions.json).

Use Kết nối for Connection, phiên for Session, khung for Pane, thư mục for Folder,
tệp for File, máy chủ for Host/Server, khóa công khai/khóa riêng for public/private
key, and Trợ lý AI for AI Assistant. Retain terminal, shell, tmux, ProxyJump and
established Git command terms; translate their surrounding instructions. Existing
IT Ops domain names Site, Rack and Playbook are retained for consistency.

The eight stale-English keys are `settings.importSettingsConfirm`,
`settings.defaultKeyHint`, `settings.defaultSshPortHint`, `settings.proxyJumpHint`,
`settings.copyOnSelect`, `settings.scrollbackHint`, `settings.urlDefaults`, and
`settings.urlDataShardsHint`. In particular, clearing a URL shard removes its
partition label; the translation does not promise deletion of browser storage.

No English keys, other locales, runtime components, or localization backlog
entries are changed. This pass does not certify every existing Vietnamese
translation or validate every other locale's value quality. Equality checks cannot
catch all stale or partially translated prose; contextual review is still needed.
